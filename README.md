# 

# Install

In the root folder of the project:

1. `npm install`
2. `npm run test:install`

# Insert credentials

1. Make sure you have an account for testing on [https://conduit.mate.academy/](https://conduit.mate.academy/).
2. Copy and paste your email and password into `/tests/auth/signin.data.json` file.

# Run tests

In the root folder of the project:

1. `npm run test:start`
2. `npm run test:report`
